# Update README.md

Automatically maintains and updates the `README.md` file by scanning the project structure and generating documentation that follows the existing formatting conventions.

## Features

- Auto-detects project structure (extensions, skills, configurations)
- Maintains consistent markdown formatting with the existing style
- Generates tree view structure for project organization
- Formats sections with appropriate headers (## for sections)
- Creates bulleted lists for features, purposes, and items
- Adds descriptions for each extension and skill

## Usage

Trigger this skill when you want to regenerate or update the project's `README.md` file. The skill will:

1. Scan the project for directories and files
2. Categorize items into Extensions, Skills, and Agent Configurations
3. Generate descriptions for each item based on its contents
4. Update the README.md with consistent formatting

## Style Conventions

- Use **bold** text for emphasis on key terms
- Use bullet points for lists
- Use headers with # and ## hierarchy
- Include a code block with tree view for structure
- Keep descriptions concise and informative
- Follow existing capitalization and punctuation patterns

## Notes

- Personal settings files will be mentioned but with a note about privacy
- AI-generated content may include disclaimers about potential errors
- Personal information should be kept generic to protect user privacy
